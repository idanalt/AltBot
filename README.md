# 🤝 AltBot – חדר צוות של סוכני AI

AltBot מאפשר להקים **צוות של סוכנים**, לתת לכל אחד מהם **תפקיד** משלו, ולתת לצוות משימה.
הסוכנים **מדברים אחד עם השני** – כל אחד רואה מה האחרים אמרו, מגיב, מתווכח ומשפר – ובסוף
**מנהל הצוות** כותב לך את **התוצאה הסופית** לפי מה שביקשת.

## איך זה עובד

```
הבקשה שלך
   │
   ▼
┌──────────── דיון ────────────┐
│ סוכן 1 → סוכן 2 → סוכן 3 → … │  ← כל סוכן רואה את כל הדיון עד עכשיו
│        (כמה סבבים)          │
└──────────────────────────────┘
   │   מנהל הצוות מחליט אם ממשיכים או שמספיק
   ▼
מנהל הצוות כותב את התוצאה הסופית
```

יש שני מצבי דיון:

| מצב | מה קורה |
|---|---|
| `round_robin` – סבבים | כל הסוכנים מדברים לפי הסדר, סבב אחרי סבב. אחרי כל סבב המנהל יכול לעצור מוקדם אם הצוות כבר הגיע להסכמה. |
| `moderated` – בהנחיית מנהל | המנהל בוחר בכל פעם מי ידבר עכשיו ונותן לו הנחיה ממוקדת, עד שהוא מחליט שיש מספיק כדי לסכם. |

## התקנה

צריך Python 3.10+ ומפתח API של Anthropic.

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
```

## הפעלה

### ממשק ווב (מומלץ)

```bash
python -m altbot web
```

ואז לפתוח בדפדפן: http://127.0.0.1:8000

בממשק אפשר:
- לבחור תבנית צוות מוכנה או לבנות צוות משלך (➕ הוסף סוכן)
- לכתוב לכל סוכן שם, אימוג'י ותפקיד (אפשר בעברית או באנגלית)
- לבחור מצב דיון, מספר סבבים, מודל ועומק חשיבה
- לראות את הסוכנים מדברים **בזמן אמת**, ובסוף לקבל את התוצאה עם כפתור העתקה

הצוות האחרון שהגדרת נשמר אוטומטית בדפדפן.

### משורת הפקודה

```bash
python -m altbot run teams/product.yaml "תכננו לי אפליקציה לניהול תקציב משפחתי"
python -m altbot run teams/research.yaml "האם כדאי לעבור לרכב חשמלי ב-2027?" --mode moderated
```

## הגדרת צוות משלך

צוות מוגדר בקובץ YAML בתיקייה `teams/` (כל קובץ שם מופיע אוטומטית בממשק):

```yaml
name: הצוות שלי
mode: round_robin        # או moderated
rounds: 2                # round_robin: מספר סבבים
max_turns: 8             # moderated: מקסימום תורות
language: Hebrew         # השפה שבה הסוכנים כותבים
model: claude-opus-5-5   # מודל ברירת מחדל לכל הסוכנים
effort: medium           # low / medium / high / xhigh / max
agents:
  - name: שף
    emoji: 👨‍🍳
    role: אתה שף מקצועי. תציע מנות, טעמים ושילובים.
  - name: תזונאית
    emoji: 🥗
    role: את תזונאית. תדאגי שהתפריט בריא ומאוזן.
    model: claude-sonnet-5-5   # אפשר מודל שונה לכל סוכן
leader:
  name: מנהל המסעדה
  emoji: 🧭
  role: אתה מסכם את הדיון וכותב תפריט סופי ומסודר.
```

תבניות מוכנות:
- `teams/product.yaml` – צוות מוצר (מנהלת מוצר, מהנדס, מעצבת UX, פרקליט השטן)
- `teams/research.yaml` – צוות מחקר (חוקרת, אנליסט, ספקן) בהנחיית עורכת ראשית
- `teams/content.yaml` – צוות תוכן ושיווק (קופירייטרית, אסטרטג, עורכת לשון)

## שימוש מתוך קוד

```python
import asyncio
from altbot import Orchestrator, load_team_file

async def main():
    team = load_team_file("teams/product.yaml")
    async for event in Orchestrator(team).run("רעיון למשימה"):
        if event["type"] == "final":
            print(event["text"])

asyncio.run(main())
```

## הערות

- ברירת המחדל היא Claude Opus 5.5. כל סוכן מקבל קריאה נפרדת ל-API בכל תור, כך שצוות גדול
  עם הרבה סבבים עולה יותר – אפשר להוריד עלויות עם פחות סבבים, `effort: low`, או מודל קטן יותר
  (Sonnet / Haiku) לחלק מהסוכנים.
- מופעל fallback בצד השרת (`fallbacks: "default"`): אם המודל מסרב לבקשה, היא מועברת אוטומטית
  למודל חלופי. אפשר לכבות עם `fallbacks: false` בקובץ הצוות.
