# 🤝 AltBot: חדר צוות של סוכני AI

AltBot מאפשר להקים צוות של סוכנים, לתת לכל אחד מהם תפקיד ולתת לצוות משימה.
הסוכנים מדברים אחד עם השני: כל אחד רואה מה האחרים אמרו, מגיב, מתווכח ומשפר.
בסוף **מנהל הצוות** כותב לך את **התוצאה הסופית**.

כל המערכת היא דף אינטרנט אחד ([`index.html`](index.html)). אין שרת ואין מה להתקין:
הדף פונה ישירות מהדפדפן ל-Claude API עם מפתח ה-API שלך.

## הפעלה

**אפשרות 1: אתר באינטרנט (GitHub Pages)**

1. בריפו ב-GitHub: **Settings** ← **Pages**.
2. תחת **Source** לבחור **Deploy from a branch**.
3. לבחור את הענף `claude/multi-agent-system-y3qy20` ואת התיקייה `/ (root)`, וללחוץ **Save**.
4. אחרי דקה-שתיים האתר יהיה זמין בכתובת https://idanalt.github.io/AltBot/

**אפשרות 2: בלי אתר.** מורידים את `index.html` ופותחים אותו בדפדפן בלחיצה כפולה.

## שימוש

1. בפעם הראשונה פותחים את **הגדרות החיבור** ומדביקים מפתח API של Anthropic.
   מפתח מקבלים ב-https://console.anthropic.com/settings/keys (צריך להוסיף קרדיט תחת Billing).
2. בוחרים צוות מוכן, או עורכים ומוסיפים סוכנים: שם, אימוג'י ותפקיד.
3. כותבים מה רוצים ולוחצים **התחילו לעבוד**.
4. רואים את הדיון בזמן אמת, ובסוף מעתיקים או מורידים את התוצאה.

אפשר לשמור צוותים משלך. הם נשמרים בדפדפן ומופיעים תחת "הצוותים שלי".

## מצבי דיון

| מצב | מה קורה |
|---|---|
| בסבבים | כל הסוכנים מדברים לפי הסדר, סבב אחרי סבב. אחרי כל סבב המנהל יכול לעצור אם הצוות כבר הסכים. |
| המנהל בוחר מי מדבר | המנהל בוחר בכל פעם מי ידבר ונותן לו הנחיה, עד שיש מספיק כדי לסכם. |

## עלויות

התשלום הוא לפי שימוש בחשבון ה-API שלך. כל תור של כל סוכן הוא קריאה נפרדת, ולכן צוות גדול
עם הרבה סבבים עולה יותר. אפשר לחסוך עם פחות סבבים, עומק חשיבה נמוך, או מודל זול יותר
(Sonnet או Haiku) בהגדרות החיבור.

## אבטחה

מפתח ה-API נשמר רק ב-`localStorage` של הדפדפן שלך ונשלח רק ל-`api.anthropic.com`.
הוא לא נשמר בריפו. מי שפותח את האתר צריך להכניס מפתח משלו.
אל תכניס את המפתח שלך במחשב שאינו שלך.
