# 🤝 AltBot: חדר צוות של סוכני AI

**פותחים את הקישור ומתחילים. אין מה להתקין ואין צורך במפתח API:**
https://claude.ai/artifact/XqVgjPy9JNaCqdJxya3nsC

AltBot מאפשר להקים צוות של סוכנים, לתת לכל אחד מהם תפקיד ולתת לצוות משימה.
הסוכנים מדברים אחד עם השני: כל אחד רואה מה האחרים אמרו, מגיב, מתווכח ומשפר.
בסוף **מנהל הצוות** כותב לך את **התוצאה הסופית**.

## איך משתמשים

1. פותחים את הקישור ב-claude.ai (מחוברים לחשבון).
2. בוחרים צוות מוכן, או עורכים ומוסיפים סוכנים: שם, אימוג'י ותפקיד.
3. כותבים מה רוצים ולוחצים **התחילו לעבוד**.
4. בפעם הראשונה Claude יבקש אישור להשתמש בחשבון שלך.
5. רואים את הדיון בזמן אמת, ובסוף מעתיקים את התוצאה.

אפשר לשמור צוותים משלך. הם נשמרים בחשבון שלך ומופיעים תחת "הצוותים שלי".

## מצבי דיון

| מצב | מה קורה |
|---|---|
| בסבבים | כל הסוכנים מדברים לפי הסדר, סבב אחרי סבב. אחרי כל סבב המנהל יכול לעצור אם הצוות כבר הסכים. |
| המנהל בוחר מי מדבר | המנהל בוחר בכל פעם מי ידבר ונותן לו הנחיה, עד שיש מספיק כדי לסכם. |

## צוותים מוכנים

- צוות מוצר
- צוות מחקר וניתוח
- צוות תוכן ושיווק
- חדר החלטות אישי

## איך זה בנוי

כל האפליקציה היא קובץ אחד: [`app/altbot.html`](app/altbot.html). הוא רץ כ-Artifact ב-claude.ai,
והקריאות ל-Claude עוברות דרך החשבון של מי שפותח את הדף, בלי שרת ובלי מפתח API.
כל תור של כל סוכן הוא קריאה נפרדת ל-Claude, כך שצוות גדול עם הרבה סבבים צורך יותר מהמכסה שלך.
